## Accepted limits and next boundaries

At 170,000 synthetic shipments, large-tenant free-text searches use sequential heap scans, requiring future indexing for million-row scale. Severe CPU starvation can exceed the internal 25-second application budget in external wall-clock time. Rate/concurrency limits are per API instance, not distributed across replicas. Export audit proves preparation rather than client receipt. Production-like multi-node failover and sustained load were not exercised. These limitations are disclosed and accepted for G11/G12 scope, not waived for release.
